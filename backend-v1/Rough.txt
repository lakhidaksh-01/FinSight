1. Forgot Password — Send OTP
POST /api/auth/forgot-password

Request:

{
  "email": "user@gmail.com"
}

What happens:

Backend checks whether the email exists.
Generates a 6-digit OTP.
Hashes the OTP and stores it.
OTP expires after 90 seconds.
Sends the OTP to the user's registered email.

Example response:

{
  "success": true,
  "message": "If an account with that email exists, an OTP has been sent."
}
2. Verify OTP
POST /api/auth/verify-otp

Request:

{
  "email": "user@gmail.com",
  "otp": "482913"
}

Backend checks:

Is the OTP correct?
Has 90 seconds passed?
Has this OTP already been used?

If correct:

{
  "success": true,
  "message": "OTP verified successfully",
  "data": {
    "resetToken": "..."
  }
}

The frontend keeps that resetToken temporarily.

3. Reset Password
POST /api/auth/reset-password

Request:

{
  "email": "user@gmail.com",
  "resetToken": "token-from-previous-api",
  "newPassword": "newpassword123"
}

Backend:

Checks the reset token.
Checks that the reset session hasn't expired.
Hashes the new password.
Updates the user's password.
Deletes the password-reset record.

Response:

{
  "success": true,
  "message": "Password reset successfully"
}
Complete frontend flow
Forgot Password page
        ↓
Enter email
        ↓
POST /api/auth/forgot-password
        ↓
OTP arrives in user's email
        ↓
Enter 6-digit OTP
        ↓
POST /api/auth/verify-otp
        ↓
Receive resetToken
        ↓
Enter new password
        ↓
POST /api/auth/reset-password
        ↓
Password changed ✅
        ↓
Login with new password
